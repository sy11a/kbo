## changelog

- kbo's build references the `Sy11a.Analyzers` policy package (0.5.0, restored from GitHub Packages), so every local and CI build enforces it; restoring needs a `read:packages` token locally ([BL-503](docs/cases/BL-503-sy11a-analyzers-package/summary.md)).

## journal

- Decision: the policy comes in through `Directory.Build.props` and a repository `nuget.config` with package source mapping (`Sy11a.*` from GitHub, everything else from nuget.org), credentials only outside the repository: `GITHUB_TOKEN` with `packages: read` in CI (shape proven end to end in sy11a_analyzers R-070), a read-only classic PAT locally. Decision: kbo stays public with a private package (operator); forks cannot restore. No dead ends.
