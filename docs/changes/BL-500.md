## changelog

- kbo carries no `[SuppressMessage]` under the `Sy11a.Analyzers` policy: SQL helpers take one constant per command, ULIDs and backoff jitter use the OS CSPRNG, and capture's fail-safe catches by type with a last-chance handler that still logs the drop and exits 0 ([BL-500](docs/cases/BL-500-sy11a-no-suppressions/summary.md)).

## journal

- Decision: CA2100 is met by assigning one constant per `CommandText` through a delegate, the shape foundry BL-496 measured (a `string` parameter, a ternary or a switch of constants still fire); the `LIMIT` caps became bound parameters, which DuckDB accepts. Decision: CA1031 on the hook path keeps ADR-0029 through typed catches plus an `UnhandledException` handler that calls `Environment.Exit(0)` (verified: exit code 0 on .NET 10); the handler is wired only at the process entry so in-process tests never install it. No dead ends.
