# Working Language

- Discussion with the operator happens in Russian — chat only.
- Every repository artifact is written in English: backlog, cases/specs,
  ADRs, OKF docs, journal, changelog, commit messages, PR titles/bodies.
- Quoting a Russian UI string or an operator decision inside English prose
  is quotation, not a violation; the prose around it stays English.
- Russian prose found in a doc is fixed in the same task that noticed it.
