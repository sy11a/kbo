# Skill Law (this repo)

Per `docs/ai/rules/core/skills.md`: law beats skills; outputs redirect to
constitutional homes. Stage map for this repo — consult at stage boundaries:

- **Pre-plan:** `grilling`, `grill-me`, `design-an-interface`, `codebase-design`
- **Implement:** `tdd`
- **Debug:** `diagnosing-bugs`
- **Review:** `dotnet-refactoring`, `code-review`
- **Docs/research:** `research` (findings land under `docs/okf/`, linked from the index), `handoff`

Discouraged — use only with redirects applied:
- `qa`, `to-tickets`, `triage`, `request-refactor-plan`, `wayfinder` — issue/ticket output → `docs/backlog.md`
- `domain-modeling`, `ubiquitous-language`, `grill-with-docs` — glossary/CONTEXT writes → `docs/okf/glossary.md` rows

- **Banned patterns:** any skill step that auto-commits, pushes, merges, or
  edits `settings.json`/hooks without an explicit decision-gate stop.
